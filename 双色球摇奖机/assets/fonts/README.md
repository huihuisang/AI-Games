# Result Quote Font

Ma Shan Zheng by the MaShanZheng Project Authors, distributed under the SIL Open Font License. Source: https://github.com/googlefonts/mashanzheng .

`lucky-brush.woff2` is a Google Fonts text subset containing all characters in the current 80 mascot lines, character names, and direct-selection fallback. It is loaded only when the result image is composed. Live number labels and metadata continue to use the system UI font. Regenerate the subset when adding characters to the dialogue pools. Keep the accompanying OFL file.
