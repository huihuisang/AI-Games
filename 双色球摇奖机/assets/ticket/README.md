# Guardian Result Assets

Production assets for the selected first concept, `../../../design/lottery-ticket/mascot-focus/01-guardian-slip.png`.

| Delivery file | Size | Use | Source and exact prompts |
| --- | --- | --- | --- |
| `guardian-backdrop.webp` | 900 × 1700 | Cream clouds, gold coins, and halo behind the live mascot and quote | `guardian-backdrop.png`, [generation record](guardian-backdrop.md) |
| `guardian-paper-roomy.webp` | 900 × 440 RGBA | Active paper plate with higher perforation and a roomier lower stub | `guardian-paper-roomy-source.png`, [generation record](guardian-paper.md) |
| `guardian-paper.webp` | 900 × 440 RGBA | Previous compact-stub plate kept as design history | `guardian-paper.png`, `guardian-paper-source.png`, [generation record](guardian-paper.md) |
| `guardian-neutral.webp` | 640 × 640 RGBA | Neutral ingot for direct selection and legacy records | `guardian-neutral.png`, [generation record](guardian-neutral.md) |

All artwork was produced with the built-in imagegen tool using the selected image as a real visual reference. Delivery conversion preserves aspect ratio and transparency where present. No browser screenshot or sample text is used as an application template. The renderer adds the actual mascot, blessing, numbers, time, ID, and preset information.

The original four mascot assets remain in `../mascots/`. The licensed brush-font subset is in `../fonts/`. Action icons use Phosphor Core 2.1.1, already covered by `../PHOSPHOR-LICENSE.txt`.
