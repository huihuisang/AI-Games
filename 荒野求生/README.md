# Wildbound

Wildbound is a compact top-down wilderness survival game built with plain HTML, CSS, and JavaScript.

The survivor uses a 24-frame directional walk cycle: six animation frames for each of the front, back, left, and right movement directions.

## Objective

Explore the forest, gather supplies, craft essential equipment, survive the creatures that emerge at night, and stay alive for 20 full days until rescue arrives.

## Controls

- `WASD` or arrow keys: Move
- `E`: Interact, gather, eat, or drink
- `Space`: Attack
- `C`: Open or close the crafting menu
- Touch devices: Use the on-screen joystick and action buttons

## Run locally

Open `index.html` in a modern browser. No installation or build step is required.
