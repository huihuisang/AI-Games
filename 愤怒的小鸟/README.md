# 愤怒的小鸟 2 · 仿制版

仿照《愤怒的小鸟 2》核心玩法自制的一款弹弓物理破坏游戏，纯原生 HTML5 Canvas +
JavaScript 实现，零依赖、离线可玩。打开 `index.html` 即可开始。

## 玩法

- **弹弓弹射**：按住弹弓上的鸟向后拖，松手发射（屏幕上会显示弹道预览点）。
- **出鸟卡组（AB2 标志性玩法）**：底部是本关的出鸟卡组，发射前点击任意一张卡即可换鸟。
- **空中技能**：鸟在飞行时点击屏幕触发：
  - 🔴 **大红**：战吼冲击波，震开周围障碍
  - 🟡 **飞镖黄**：向前冲刺，克制木头
  - 🔵 **蓝弟弟**：一分为三，克制冰块
  - ⚫ **炸弹黑**：原地爆炸，克制石头（撞击后引信也会自动点燃）
  - ⚪ **白公主**：俯冲投下爆炸蛋，自身向上弹开
- **可破坏世界**：木头 / 石头 / 冰块三种材料各有血量与克制关系，TNT 会连锁爆炸，
  结构倒塌、挤压都能消灭绿猪（含戴头盔的猪王）。
- **摧毁率与星级**：按摧毁价值计算摧毁率（未用的鸟卡也计入），55% 两星、80% 三星，
  通关进度自动存档（localStorage）。
- **镜头**：开场自动巡视猪堡；拖动空白处平移，滚轮 / 双指缩放。
- **快捷键**：`R` 重开 · `P`/`Esc` 暂停 · `M` 静音。共 8 关。

## 技术实现

| 文件 | 说明 |
| --- | --- |
| `physics.js` | 自研 2D 刚体物理引擎（Box2D-lite 风格）：OBB SAT 碰撞 + 面裁剪生成接触点、顺序冲量求解、摩擦 / 弹性、Baumgarte 位置修正、刚体休眠防蠕滑、高速自适应子步长防穿透 |
| `levels.js` | 数值表（材料 / 鸟 / 猪 / TNT）与 8 关的声明式关卡数据 |
| `game.js` | 游戏主逻辑：弹弓与卡组、五类鸟技能、伤害与克制系统、爆炸与连锁、粒子 / 漂浮得分、视差背景与手绘角色、相机系统、WebAudio 合成音效、菜单 / 结算 UI |

物理引擎的稳定性与伤害数值由无头 Node 测试校准（各关卡静置无自发破坏、
弹射冲击冲量 → 伤害映射）；页面另暴露 `window.__AB2` 调试句柄，
可在控制台手动驱动帧（`__AB2.step()`）便于排查问题。
